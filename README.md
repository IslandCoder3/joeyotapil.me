# Joey Otapil — Web Developer Portfolio

This is my personal portfolio site. I'm a Level III Front-End Web Developer at Proweaver Inc., specializing in HTML, CSS, and WordPress, and I built this as a single-page, dark-themed showcase of my work, skills, and background for potential clients and employers.

## About the Project

The portfolio is one continuous scrolling page with a fixed sidebar for navigation, moving through:

- **Home** — an animated intro with my name, title, and a particle-effect background
- **About Me** — a short bio alongside my personal details (name, location, birthday, degree, contact info)
- **Experience** — my current role at Proweaver Inc., plus a full list of my core skills (HTML, CSS, JavaScript, PHP, WordPress, Elementor, Divi, responsive design, Git, SEO, performance optimization, and more)
- **Portfolio** — a grid of real client and personal projects I've built, each with a screenshot, description, tools used, and a live link. Projects are filterable by category (e.g. Business/E-commerce, Travel & Tourism, Education, Nonprofit/Community, Game Dev)
- **Certificates** — a searchable gallery of certificates and awards I've received, viewable in a lightbox
- **Testimonials** — feedback from past clients and organizations I've worked with
- **Contact** — my location, email, phone, and an embedded map

I went with a dark navy palette with cyan/violet accents, a monospace-and-display font pairing (Space Grotesk, Inter, JetBrains Mono), and small interactive touches throughout — scroll-spy navigation, fade-in animations, a resume preview modal, and a cursor-reactive particle canvas on the hero section — to give the site a modern, developer-portfolio feel without leaning on a template.
